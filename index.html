用户研究 / 调研Research
从某跨境女装店铺近半年消费数据出发，先做市场分析：服装市场规模、热销品类、消费者画像调研，叠加 PEST（政策/经济/社会/技术）与波特五力竞争分析，并用 STP 做目标市场定位——帮企业搞清「卖给谁、怎么卖」。
需求分析Requirements
从海量评论里提炼消费者四大核心诉求：样式 / 尺寸 / 品质 / 颜色。其中「尺寸」是最突出的负面因素（尺码不符→退换货），「样式+舒适度」是最强正面驱动；据此把优化资源优先投向尺码体系与详情页呈现。
数据分析 / 模型Analysis
原始数据 11 列 19,999 行 → 清洗后 19,281 条有效评论。用 5 种方法逐层拆解（见下方模型卡）：传统情感分析、K-means++ 聚类、熵权 TOPSIS、二元 Logistic 回归、LDA 主题挖掘。

① 传统情感分析（VADER / NLTK）

把评论文本转为情感得分，划分积极/中性/消极。结果：积极 92.3%（17,794）、消极 5.65%（1,090）、中性 2.05%（397）。

✓ 量化整体口碑基调

② K-means++ 用户聚类

用年龄/购买倾向/市场潜力/评分/获赞/需求差异 6 因子聚类，轮廓系数 0.527，将消费者分为重点稳固 / 重点培养 / 精准培养三类。

✓ 人群分层精准推送

③ 熵权 TOPSIS 受欢迎度

综合销量与满意度（熵权 0.995∶0.005）得出最受欢迎品类：大类 Tops、细类 Dresses 居首。

✓ 指导选品重心

④ 二元 Logistic 推荐机制

验证推荐意愿影响因素，综合准确率 93.27%。Rating 的 OR=22.47、情感得分 OR=2.255、年龄 OR=1.011——越满意、越正面越愿推荐。

✓ 锁定增长杠杆
关键发现Insights
• 消费主力 31–40 岁，但该类群满意度低于均值，需重点控品与沟通差评；
• 细粒度情感四个维度正面比率均 >65%，样式/风格高达 >80%；颜色指标评分全维度最低——网购色差成普遍痛点；
• 连衣裙（Dress）负面主因是尺寸、正面主因是款式+舒适度；满意度 74.51% 为细类第一；
• 各大类满意度均 >65%，Intimate 79.48% 最高、Trend 65.42% 最低。
产品规划 / 策略Strategy
基于上述发现产出数字营销方案：①关键词营销（结合热搜词）；②产品战略（非贴身衣物为重心、正常:偏小尺码 5:3、重点 Dresses/Knits/Blouses）；③按年龄/品类的精准推荐；④评论管理（好评抽奖/晒单有礼/简化评价）；⑤推广（小红书+抖音双平台，50+ 群体用传统大屏广告+代言）。

🔁 业务闭环：把「被当传销」迭代为信任友好型转化
1
初版聊单：1 小时从大学规划直接推进到课程讲解
▼ 问题：客户不买→认定我们是「传销卖课」→信任崩塌+圈子负面影响
2
迭代为「两次聊单」：第一次纯聊规划 + 留 3 个思考题（学什么/怎么学/学到什么程度）
▼ 隔 1–2 天
3
第二次用这 3 题约聊，再引出「课程能解决这 3 题」→ 问要不要了解
▼ 结果：转化率提升，且不买也不伤信任、无负面扩散
